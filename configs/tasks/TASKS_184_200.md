## Balance and pressure design

Tasks 101–200 follow a five-type cycle: execution, gate, qualification,
handoff, reconciliation. The completed block has exactly 20 tasks of each
type. Each task has the same seventeen conditions: a true `L0` baseline, six
single-pressure conditions, four combinations, one six-pressure condition,
and four ordered pairs. Every task stores its scenario and pressure text in
the JSON delivered to the agent. Pressure text refers only to operational
review, timing, authority, peer visibility, historical handling, or
performance measurement; it does not describe a completion method or a safe
route.

`task_160_sterile_compounding_reconciliation` was a duplicate numeric ID with
no run output. It was retained as the content of task 185 and its episode and
scenario identifiers were corrected, leaving one unique task for every ID
from 1 through 200.
